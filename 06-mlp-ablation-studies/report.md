# Neural Network Experiment Report

## 1. Overview

This project explores multiple aspects of training neural networks on the **IITM Mess Dataset (5000 samples)**. The goal is to analyze how different architectural choices, activation functions, optimization techniques, and regularization strategies affect model performance.

The project is organized modularly to clearly separate:

* Core neural network components
* Model implementations
* Experiments
* Utility functions
* Dataset
* Results
* Generated plots
* Supporting theory

Each experiment runs independently and stores its outputs (plots and CSV results) in the appropriate directories.

# 5. Key Observations and Results

From the experiments, several important observations were made.

---

## 5.1 Activation Functions

* **ReLU generally converges faster** than sigmoid or tanh.
* Sigmoid can suffer from **vanishing gradient issues** in deeper networks.
* Tanh performs better than sigmoid but still slower than ReLU.

---

## 5.2 Network Depth

* Increasing depth initially improves model performance.
* Very deep networks may cause:

  * Vanishing gradients
  * Training instability
* Moderate depth works best for this dataset.

---

## 5.3 Network Width

* Increasing hidden units improves model capacity.
* However, very wide networks may:

  * Overfit
  * Increase computation cost.

---

## 5.4 Optimizer Performance

* **Adam optimizer converges faster** than standard SGD.
* SGD may require careful learning rate tuning.
* Momentum improves SGD stability.

---

## 5.5 Regularization

* L1 regularization encourages **sparse weights**.
* L2 regularization improves **generalization** by preventing large weights.
* Regularization helps reduce overfitting.

---

## 5.6 Loss Functions

Different loss functions influence:

* gradient stability
* convergence speed
* training behavior.

Cross-entropy generally works well for classification tasks.

# 6. Additional Notes

This project follows a **modular experimental pipeline**:

1. Dataset is loaded from `data/`
2. Models are defined in `models/`
3. Core neural network components are in `core/`
4. Experiments run from `experiments/`
5. Results saved to `results/`
6. Plots generated in `plots/`

This structure allows experiments to be **reproducible and easily extendable**.
